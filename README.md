「NFCタグ＝鍵」「ライト＝錠」<br>
登録したNFCタグをかざした時だけ点灯する、"鍵付き"のスマートライト。

NFCリーダーを搭載したマイコンと専用のAndroidアプリをBLEで連携させ、<br>
「かざす」というシンプルな動作で、登録者だけがライトを操作できる体験を目指しています。

## 🌟 特徴とこだわり

- **NFCタグが「鍵」になる**: あらかじめ登録したNFCタグをかざした時だけライトがON/OFF。未登録のタグには反応しません。
- **アプリでかんたん初期設定**: スマホアプリからBLEで接続し、パスワードと秘密の質問を設定。そのまま鍵（NFCタグ）の登録まで進めます。
- **鍵の管理もアプリから**: 鍵の追加・削除、パスワードの再設定をアプリから行えます。パスワードを忘れても、秘密の質問で認証できます。
- **安全性を意識したモード設計**: 普段はNFCでの操作のみを受け付け、設定は本体の物理ボタンを押した時だけ可能に。3分間操作がなければ自動で通常モードに戻ります。
- **小型・省スペース**: 親指サイズのマイコンボード（XIAO ESP32C3）を採用し、さまざまな場所に設置しやすい形状を目指しています。

## 🛠 技術スタック

### ハードウェア / マイコン
- **Board**: Seeed Studio XIAO ESP32C3
- **NFC Reader**: PN532（I2C接続）
- **Framework**: Arduino（PlatformIO）
- **Library**: Adafruit PN532
- **通信**: BLE（Bluetooth Low Energy）
- **データ保存**: Preferences（ESP32の不揮発メモリ）

### アプリケーション
- **Platform**: Android（minSdk 24 / targetSdk 35）
- **Language**: Kotlin
- **UI**: Jetpack Compose（Material 3）
- **画面遷移**: Navigation Compose

## 🧩 システム構成

```
[NFCタグ（鍵）] ──かざす──▶ [PN532 NFCリーダー]
                                  │ I2C
                                  ▼
 [物理ボタン] ──────────▶ [XIAO ESP32C3] ──▶ [ライト]
                                  ▲
                                  │ BLE
                                  ▼
                        [Androidアプリ]
                （初期設定・鍵の管理・ライト操作）
```

## 🔄 デバイスの動作モード

| モード | 内容 | 次のモードへ |
| --- | --- | --- |
| 初回セットアップ | アプリからパスワードと秘密の質問を登録 | 登録が完了すると鍵登録へ |
| 鍵登録 | かざしたNFCタグを鍵として保存 | 保存すると通常待機へ |
| 通常待機 | 登録済みの鍵をかざすとライトをON/OFF | 物理ボタンを押すと設定へ |
| 設定 | アプリで認証後、鍵の追加・削除やパスワードの再設定を実施 | 終了操作、または3分間操作なしで通常待機へ |

## 📱 アプリの画面構成

1. デバイス検索・接続（BLE）
2. 新規登録（パスワード → 秘密の質問）／ログイン
3. パスワードリセット（秘密の質問で認証）
4. ホーム（ライトのON/OFF・デバイスの状態確認）
5. 鍵の管理／秘密の質問の編集

## 🚀 開発環境のセットアップ

### マイコン（Micom）
1. VS Code に [PlatformIO](https://platformio.org/) 拡張機能をインストール
2. `Micom` フォルダを PlatformIO プロジェクトとして開く
3. XIAO ESP32C3 を USB で接続し、ビルドして書き込む

```zsh
cd Micom
pio run -t upload
```

### アプリケーション（Application）
1. Android Studio で `Application` フォルダを開く
2. Gradle の同期が終わったら、実機（Bluetooth対応のAndroid端末）を接続して実行する
