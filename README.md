「タッチするだけで、光で応える」<br>
NFCタグにかざすだけで、ライトが反応するインタラクティブデバイス。

NFCリーダーを搭載したマイコンとアプリを連携させ、<br>
「かざす」というシンプルな動作を、光による直感的なフィードバックに変えることを目指しています。

## 🌟 構想中の特徴

- **かざすだけの操作**: NFCタグをリーダーにかざすだけで反応。説明不要で誰でも使えるシンプルな操作系。
- **光によるフィードバック**: 読み取ったタグに応じてライトの点灯・色・パターンを切り替え、結果を視覚的に伝える。
- **アプリとの連携**: 専用アプリからタグとライトの動作の紐付けや設定を行える構成を想定。
- **小型・省スペース**: 親指サイズのマイコンボード（XIAO ESP32C3）を採用し、さまざまな場所に設置しやすい形状を目指す。

## 🚀 開発環境のセットアップ

### マイコン（Micom）
1. VS Code に [PlatformIO](https://platformio.org/) 拡張機能をインストール
2. `Micom` フォルダを PlatformIO プロジェクトとして開く
3. XIAO ESP32C3 を USB で接続し、ビルド＆書き込み

```zsh
cd Micom
pio run -t upload
```
